# 要件

## 前提

- 2人で対戦するオンラインのカードゲーム。友だち同士で、主にスマホのブラウザから遊ぶ
- 遊ぶにはメールアドレスでのログインが必要。パスワード・確認メールはなし（実在しないアドレスでもよい）。Supabase Auth は使わず、アプリ独自のプレイヤー・セッションで管理する
- Supabase の無料枠はプロジェクトが2つまでなので、**ほかのアプリと同じプロジェクトに同居できる**こと（名前はすべて `trivia_battle_` で始め、認証の設定は変えない）
- ゲームのルールは旧版（so-studnet/trivia-battle）と同じ

## 機能

### F0 ログイン
- メールアドレス（大文字・小文字は区別しない）を入れて「次へ」。登録済みならそのままログイン
- 未登録なら、ニックネーム（1〜12文字）を決めて登録し、ログインする
- 同じ端末・同じブラウザでは、次からログインを省ける（端末ごとのセッションを localStorage に保存）
- 別の端末でも、同じメールアドレスでログインすれば同じプレイヤー（成績・出会った問題）になる
- タイトル画面のニックネーム欄には、前に使ったニックネームが入っている。変えて部屋に入ると保存される
- メニューからログアウトできる
- 注意：確認がないため、メールアドレスを知っていれば他人もその人としてログインできる（了承済み）

### F1 部屋
- 名前（1〜12文字）を入れて部屋をつくると、4桁の部屋コードができる
- コードを入れると参加できる。招待リンク（`/?room=1234`）を開くとコードが入った状態になる
- 1部屋2人まで。3人目・存在しないコード・閉じた部屋はエラーを表示
- コードのコピー、招待リンクの共有（Web Share API。なければコピー）
- 再読み込み・タブを閉じて開き直しても、同じ端末（同じブラウザ）なら部屋に戻れる
- ゲストが退出すると席が空き、ホストに知らせる（対戦中なら対戦は中断）。ホストが退出すると部屋は閉じ、ゲストに知らせる

### F2 対戦の準備
- 2人とも「準備OK」にすると、ホストだけが対戦を始められる
- 対戦ルールはホストだけが変えられる：先攻（ホスト／ゲスト／ランダム）、目標点（1〜10、初期値3）
- ルールを変えるとゲストの準備OKは外れる（変更を見てもらうため）
- ランダムの先攻は対戦開始時に1回だけ決まる

### F3 対戦
- 出題者は手札4枚から1枚を出題する。出題者には答えとジャンルが見えている
- **出会った問題は出題しない**：手札に配られた問題・出題された問題は、そのプレイヤーにとって「出会った問題」になり、2人のどちらかが出会った問題は新しく配らない
- 消費を少なくするため、**手札は持ち越す**：出題しなかったカードは手札に残り、次に出題者になったときに足りない分（ふつうは1枚）だけ補充する。対戦が終わったときの手札も次の対戦に持ち越す（新しい相手がすでに出会った問題は外す）
- 補充するカードは、手札のジャンルがなるべくばらけるように選ぶ
- 2人とも出会っていない問題がなくなったら、この対戦より前に出会った問題のうち、出会ったのが古いものから配る
- 出題者が1枚選ぶと、回答者に雑学の文が表示される
- 回答者は賭け点（1〜3）を選び、「本当」か「ウソ」で答える
- 正解なら回答者に、不正解なら出題者に賭け点が入る
- 結果画面で答え・解説・点の動きを見せる。2人とも「次の問題へ」を押したら、出題者を交代して次の問題
- どちらかが目標点に届いたら終了。勝者・最終スコア・出題された雑学の一覧（解説つき）を表示
- 「もう一度あそぶ」で同じ部屋・同じ設定のまま準備画面に戻る
- 対戦の終わりに、その相手との通算成績（○勝○敗）を表示する

### F4 成績（自分の分だけ見られる）
- 勝敗・勝率、回答者としての正答率、出題者として相手をだませた率
- ジャンル別の正答率（8ジャンル）、賭け点別の正答率、回答で得た点・相手に渡した点
- 対戦相手ごとの勝敗、出会った問題の数（全500問中）

### F5 フィードバック
- ログイン画面・タイトル画面のメニュー・対戦終了画面から「ご意見・不具合の報告」を送れる（1〜2000文字）
- Supabase に保存し、開発者のメールアドレス（Vercel の環境変数 `FEEDBACK_TO_EMAIL`）に Resend で送る。メールに失敗しても保存はされる
- 送りすぎ防止：同じプレイヤーは10分に3件まで、全体で1時間に30件まで。ボット対策のおとり欄

### 問題データ
- 500問（旧版の120問 + 追加380問）。本当とウソがほぼ半分ずつ
- 問題の基準：答えが「本当」か「ウソ」にはっきり決まる／ウソはありがちな思い込みや、本当らしく少しだけ違えたもの／年によって変わる記録や数は避ける／解説で正しい知識がわかる
- ジャンル：生き物・宇宙と地球・科学・人体・地理・歴史・食べ物・文化とスポーツ（各62〜64問）

## 非機能

- 相手の操作は Realtime（Broadcast）ですぐ（1秒以内を目安に）反映する。Realtime が止まっても、画面の復帰・通信の回復・10秒ごとの読み直しで追いつく
- 2人が同時に操作しても状態が壊れない（version による楽観的排他。ぶつかったら最新を読み直してやり直す）
- 部屋のデータは部屋のメンバー（合言葉を知っている人）しか読み書きできない。テーブルは直接読み書きできず、操作はすべて RPC 経由。名前・メンバー・部屋コードは RPC でしか変わらない
- 同じプロジェクトのほかのアプリのユーザー（ログイン済み）からも、このアプリのテーブルは見えない
- 動きのない部屋（12時間）と閉じた部屋は、新しい部屋をつくるときに片付ける
- スマホ優先、ダークモード対応、アニメーションは「視差効果を減らす」設定で止める
- Supabase の設定がないときは、同じブラウザの別タブ同士で遊べる「お試しモード」で動く（開発・確認用）

## 対象外（今回は作らない）

- 管理者画面（旧版の /admin）。部屋は Supabase のダッシュボードの Table Editor で見られる
- 3人以上の対戦、CPU 対戦、全員のランキング（成績は自分の分だけ）、メールアドレスの確認
- 答えを相手の端末から完全に隠すこと（雑学データはアプリに含まれているため、開発者ツールを使えば見られる。友だち同士の遊びなので許容）
