# 要件

## 前提

- 2人で対戦するオンラインのカードゲーム。友だち同士で、主にスマホのブラウザから遊ぶ
- 会員登録はしない。名前を入れるだけで遊べる（裏では Supabase の匿名サインインを使う）
- ゲームのルールは旧版（so-studnet/trivia-battle）と同じ

## 機能

### F1 部屋
- 名前（1〜12文字）を入れて部屋をつくると、4桁の部屋コードができる
- コードを入れると参加できる。招待リンク（`/?room=1234`）を開くとコードが入った状態になる
- 1部屋2人まで。3人目・存在しないコード・閉じた部屋はエラーを表示
- コードのコピー、招待リンクの共有（Web Share API。なければコピー）
- 再読み込み・タブを閉じて開き直しても、同じ端末なら部屋に戻れる
- ゲストが退出すると席が空き、ホストに知らせる（対戦中なら対戦は中断）。ホストが退出すると部屋は閉じ、ゲストに知らせる

### F2 対戦の準備
- 2人とも「準備OK」にすると、ホストだけが対戦を始められる
- 対戦ルールはホストだけが変えられる：先攻（ホスト／ゲスト／ランダム）、目標点（1〜10、初期値3）
- ルールを変えるとゲストの準備OKは外れる（変更を見てもらうため）
- ランダムの先攻は対戦開始時に1回だけ決まる

### F3 対戦
- 出題者に未使用の雑学が4枚配られる（残りが4枚未満なら使用済みをリセット）。出題者には答えが見えている
- 出題者が1枚選ぶと、回答者に雑学の文が表示される
- 回答者は賭け点（1〜3）を選び、「本当」か「ウソ」で答える
- 正解なら回答者に、不正解なら出題者に賭け点が入る
- 結果画面で答え・解説・点の動きを見せる。2人とも「次の問題へ」を押したら、出題者を交代して次の問題
- どちらかが目標点に届いたら終了。勝者・最終スコア・出題された雑学の一覧（解説つき）を表示
- 「もう一度あそぶ」で同じ部屋・同じ設定のまま準備画面に戻る

## 非機能

- 相手の操作は Realtime ですぐ（1秒以内を目安に）反映する。Realtime が止まっても、画面の復帰・通信の回復・15秒ごとの読み直しで追いつく
- 2人が同時に操作しても状態が壊れない（version による楽観的排他。ぶつかったら最新を読み直してやり直す）
- 部屋のデータは部屋のメンバーしか読み書きできない（RLS）。名前・メンバー・部屋コードはクライアントから直接は変えられない
- 動きのない部屋（12時間）と閉じた部屋は、新しい部屋をつくるときに片付ける
- スマホ優先、ダークモード対応、アニメーションは「視差効果を減らす」設定で止める
- Supabase の設定がないときは、同じブラウザの別タブ同士で遊べる「お試しモード」で動く（開発・確認用）

## 対象外（今回は作らない）

- 管理者画面（旧版の /admin）。部屋は Supabase のダッシュボードの Table Editor で見られる
- 3人以上の対戦、CPU 対戦、ランキング、ログイン
- 答えを相手の端末から完全に隠すこと（雑学データはアプリに含まれているため、開発者ツールを使えば見られる。友だち同士の遊びなので許容）
